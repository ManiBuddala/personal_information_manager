
# Personal Information Manager

A beginner-friendly Python CLI application that collects personal details from a user, validates specific inputs, calculates age in months, and displays a formatted summary.

---

## Features

- **Interactive CLI Prompts: Collects basic personal details (Name, Age, City, Hobby, Qualification).

- **Input Validation: Prevents empty inputs for favorite food and favorite color using `while` loops.

- **Data Calculation: Computes age in months (`age * 12`).

- **Formatted Output: Displays collected information inside formatted console blocks.

---

## Requirements

- Python 3.x
